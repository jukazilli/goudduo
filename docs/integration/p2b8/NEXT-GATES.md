# Próximos gates

Esta PR encerra P2-B8 para revisão, sem merge automático nem início de outra fase. O conjunto de treinos pode ser avaliado como integração funcional do protótipo nos limites em memória e navegadores testados, não como MVP pronto.

| Gate | Pendência / próxima ação necessária |
| --- | --- |
| Homologação B8 | Proprietário revê jornadas, evidências, CI e matriz de prontidão |
| QA físico | Executar protocolo iPhone/Android/VoiceOver/teclado/insets; não aprovado nesta rodada |
| Refinamento visual | Backlog regional P2; manter acesso, identidade e contratos homologados |
| Cópia/referência entre dias | Decisão de produto; shared-workout-pending continua bloqueando propagação/cópia implícita |
| Nome do treino | Limite100 do domínio versus60 do HTML requer decisão, não mudança silenciosa |
| Catálogo/equipamentos/substitutos | Catálogo profissional/direitos, Biblioteca independente e seleção de equipamento precisam recortes próprios |
| Pulse | Dados, viewer, composer/upload, visto/gradiente e ocultação por Configurações/Atividade ainda dependem de contratos e autorização |
| Sessão/Histórico/Progresso | Serviços e regras ausentes; não deduzir métricas de fixtures |
| Publicações/Business/Perfil/Auth | Integrações futuras específicas; Feed privado exige baseline e autorização granular de port/mídia |
| Publicação | Autorização separada do artefato/conta; nenhum deploy autorizado aqui |

Nenhuma operação ainda ausente é tratada como concluída por existir rota, tipo ou placeholder. Não inferir porcentagem global a partir das PRs integradas.
